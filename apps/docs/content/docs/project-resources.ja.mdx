---
title: プロジェクトリソース
description: プロジェクトに付加できるリンクやローカル参照のメタデータ。
---

プロジェクトリソースは、GitHub URL、ローカルディレクトリ参照、または API が対応する型付き参照を記録するための任意メタデータです。

プロジェクトリソースは Agent の作業ディレクトリを選択せず、リポジトリの clone や worktree の作成も行わず、リポジトリ URL を Agent の prompt に注入しません。各 Agent は常に次の永続ディレクトリで実行されます。

```text
~/.multica/workspaces/<workspace_id>/agents/<agent_id>
```

リポジトリ構成と Git 操作は Agent に委ねられます。必要に応じて Agent は自分のディレクトリで clone、pull、または Git worktree を利用できます。

## CLI

```bash
multica project resource list <project-id>
multica project resource add <project-id> --type <type> --ref '<json>'
multica project resource update <project-id> <resource-id> --ref '<json>'
multica project resource remove <project-id> <resource-id>
```

これらのコマンドはプロジェクトメタデータだけを更新し、実行 cwd には影響しません。
