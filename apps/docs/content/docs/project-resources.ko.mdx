title: 프로젝트 리소스
description: 프로젝트에 선택적으로 저장하는 링크 및 로컬 참조 메타데이터입니다.
---

프로젝트 리소스는 GitHub URL, 로컬 디렉터리 참조 또는 API가 지원하는 기타 형식화된 참조를 기록하는 선택적 메타데이터입니다.

프로젝트 리소스는 Agent의 작업 디렉터리를 선택하지 않으며, 저장소를 clone하거나 worktree를 만들지 않고, 저장소 URL을 Agent prompt에 주입하지 않습니다. 각 Agent는 항상 다음 영구 디렉터리에서 실행됩니다.

```text
~/.multica/workspaces/<workspace_id>/agents/<agent_id>
```

저장소 구조와 Git 작업은 Agent가 결정합니다. 작업에 필요하면 Agent가 자체 디렉터리에서 clone, pull 또는 기본 Git worktree를 사용할 수 있습니다.

## CLI

```bash
multica project resource list <project-id>
multica project resource add <project-id> --type <type> --ref '<json>'
multica project resource update <project-id> <resource-id> --ref '<json>'
multica project resource remove <project-id> <resource-id>
```

이 명령은 프로젝트 메타데이터만 변경하며 실행 cwd에는 영향을 주지 않습니다.
