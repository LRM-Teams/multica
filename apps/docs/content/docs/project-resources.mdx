---
title: Project resources
description: Optional project metadata for links and local references.
---

Project resources are optional metadata attached to a project. They can record a GitHub URL, a local directory reference, or another typed reference supported by the API.

Project resources do **not** choose an Agent's working directory, clone a repository, create a worktree, or inject repository URLs into an Agent prompt. Every Agent always runs in its durable workspace:

```text
~/.multica/workspaces/<workspace_id>/agents/<agent_id>
```

Multica leaves repository layout and Git operations to the Agent. An Agent may clone, pull, or create native Git worktrees inside its workspace when the task requires it.

## CLI

Inspect projects and resources through the unified workspace snapshot:

```bash
multica workspace info --projects
multica workspace info --projects --output json
```

The snapshot is read-only and does not affect execution cwd.
