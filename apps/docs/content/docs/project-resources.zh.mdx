---
title: 项目资源
description: 项目下可选的链接与本地引用元数据。
---

项目资源是挂在项目下的可选元数据，可以记录 GitHub URL、本地目录引用，或 API 支持的其他类型化引用。

项目资源**不会**选择 Agent 的工作目录，不会 clone 仓库、创建 worktree，也不会把仓库 URL 注入 Agent prompt。每个 Agent 始终在自己的持久目录中运行：

```text
~/.multica/workspaces/<workspace_id>/agents/<agent_id>
```

仓库布局与 Git 操作由 Agent 自己决定。任务需要时，Agent 可以在自己的目录中 clone、pull，或使用原生 Git worktree。

## CLI

使用以下命令查看项目及其绑定资源：

```bash
multica workspace info --projects
multica workspace info --projects --output json
```

旧版 `multica project resource` 命令已移除。资源管理请使用 workspace UI/API，
且不会影响 Agent 的执行目录。
