# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues under
`LRM-Teams/multica`. Use the `gh` CLI from inside the repository.

- Publish a spec or ticket by creating a GitHub issue.
- Read issues with their full body, comments, and labels.
- Apply `ready-for-agent` only after the work is fully specified.
- Use native GitHub blocking dependencies for ticket edges when available;
  otherwise include a `Blocked by: #...` line.
- Pull requests are not treated as a request or triage surface.
