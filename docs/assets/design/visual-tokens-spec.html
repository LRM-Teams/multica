LRM-226 · 小步统一视觉 Token

Frank 反馈「项目整体风格不一致」。本页冻结聊天 / 成员 / 设置共用的色板与字号， 用同一套 token 画三块对照表面，供拍板后再拆前端落地单。

设计门 · 待拍板 小步统一 不做整站换肤 头像规则沿用 LRM-223 / spec-b
诊断 本期范围 色板 Token 字号 Token 三表面对照 漂移点 拍板选项 前端交接

1. 问题诊断

  1. 成员稿、设置稿、头像稿各自写了一套接近但不完全相同的 CSS 变量（如 --bg #f6f6f4 vs #f3f4f2，--line #e8e8e8 vs #ddd）。
  2. --ok 与在线状态色混用：设置稿把 #2bac76 当成功色，头像稿里它是 --online；语义成功应为 #007a5a。
  3. 危险色两套：产品壳用 Slack 系 #e01e5a，文档告警用 #c23b22 —— 本期产品壳统一到前者。

根因是「表面各自抄色」而非缺品牌方向；最小改动是锁 token + 三表面吃同一变量，不是重画整站。

2. 本期统一范围（推荐）

做

  • 聊天主列：消息名/正文/时间色、分割线、输入框边框
  • Members 大弹窗 + 设置「成员」Tab 列表：同一 token 与字号阶
  • 频道设置详情：关于/设置行、危险操作色、Tab 字号
  • 把现有硬编码色换成下表变量（或等价 theme map）

不做

  • 整站换肤 / 暗色模式 / 新品牌主色
  • 侧栏导航、工作台、营销页大改
  • 改头像解析与占位规则（冻结于 LRM-223 spec-b）
  • 为「好看」引入第二套灰紫渐变或深色顶栏

7. 请 Frank / 群管拍板

选项 A · 推荐

接受本页 token 表 + 本期只改聊天 / 成员 / 设置三表面硬编码 → 变量。过门后拆前端落地子单。

选项 B

范围再缩：只先统一 Members + 设置成员 Tab，聊天列下期再吃同一 token（仍禁止整站换肤）。

拍板口径只需回：「A」或「B」。大改信息架构 / 换品牌色不在本单。

8. 前端交接要点（拍板后落地）

  1. 抽一层共享 CSS 变量（或 theme tokens），值以上表为准；三表面禁止本地再定义主色。
  2. 聊天：消息名 ink 700 / 正文 13–14 / 时间 ink-3 11–12；输入框边 line-strong。
  3. Members：对齐已冻结大弹窗结构；列表行 hover = hover；手机列表滚动另单已述，色号跟本表。
  4. 设置：Tab 12/700 激活底边 ink；危险操作只用 danger；成功/在线勿混。
  5. Avatar 状态点继续吃 LRM-223 spec-b；本单不重开头像设计审。
  6. 默认 / 加载 / 空 / 错误：沿用各表面既有态，只换色号，不另起文案体系。

本单 = 设计门。拍板通过后再开前端实现子单；本页 HTML 为验收对照。
