滚动区
顶栏 / 搜索 / 底栏固定 · 仅列表滚动
  • 弹窗（或全屏 sheet）定高：flex 列布局 + min-height: 0
  • 顶栏标题、搜索框、底栏操作：flex: 0 0 auto
  • 成员列表：flex: 1; overflow: auto; -webkit-overflow-scrolling: touch
  • 不要把 overflow 锁在外层导致整页拖不动、列表却裁切
  • 色与字号用上表 token，对齐桌面 Members 大弹窗

验收：窄屏成员 > 一屏时可指滑列表；顶栏搜索不跟着跑；无第二套配色。
